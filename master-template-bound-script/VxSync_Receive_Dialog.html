📷 Receive Inventory

Logs newly-received physical vaccine units into Lot_Expiry_Master — one row per unit, same convention live lot tracking already relies on. Scanning a box's barcode only ever prefills Lot Number and Expiry Date for you to check; it never writes anything by itself, and nothing here saves until you click Submit Batch below.

Try 📷 Scan Box first — it reads the printed barcode directly and is the most reliable. If the barcode won't scan (damaged box, smudged label, no barcode printed), try 🖼️ Scan from Photo instead — it reads the label's printed text using AI. If neither works, just type the fields in below by hand — that's always fine too.
